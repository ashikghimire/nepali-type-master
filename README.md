## 🚀 About Nepali Typing Master

**Nepali Typing Master** is a free and modern online Nepali typing practice platform designed for students, government employees, teachers, data entry operators, content writers, and professionals who want to improve their Nepali Unicode typing speed and accuracy.

Whether you are preparing for a government examination, office work, or simply want to learn Nepali typing, this platform provides structured lessons, typing tests, and detailed performance analytics.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/nepali-typing-master.git
```

Move into the project directory:

```bash
cd nepali-typing-master
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🏗️ Production Build

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
